# 🌌 INFINITUM Search Engine

INFINITUM is a modern and visually appealing search engine interface built using HTML and CSS. The project focuses on creativity, responsive design, smooth animations, and an engaging user experience.

## ✨ Features

- 🔍 Elegant search bar
- 🌈 Animated gradient background
- ✨ Animated INFINITUM logo
- 🌙 Dark mode toggle
- 📱 Responsive design for mobile devices
- 🎨 Modern UI with hover effects and animations
- 🚀 Quick access category buttons

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (for dark mode toggle)
